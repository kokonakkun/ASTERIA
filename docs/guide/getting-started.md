# ASTERIA 4.5 スタートガイド

Windows x64向けポータブル版の導入と、主要機能の使い方をまとめています。

## 1. ダウンロードと起動

1. GitHub Releasesから `ASTERIA-4.5.0-portable.exe` をダウンロードします。
2. EXEを任意のフォルダーへ置きます。インストール操作は不要です。
3. 必要に応じてPowerShellでSHA-256を確認します。

   ```powershell
   Get-FileHash .\ASTERIA-4.5.0-portable.exe -Algorithm SHA256
   ```

   正しい値:

   ```text
   3EB24089CC58026EB66538B6E904B607C379BD0AF106CF5100B390922F1C13FB
   ```

4. EXEをダブルクリックします。

配布版はAuthenticode未署名です。Windowsの保護画面が表示された場合は、入手元と
ハッシュを確認した場合に限り「詳細情報」から実行してください。

個人データはASTERIAのユーザーデータ領域にローカル保存されます。ポータブルEXEを
削除しても保存データは自動削除されません。

## 2. 画面を知る

| 画面 | できること |
|---|---|
| ホーム | 今日の意図、推奨ミッション、集中、ログを一覧 |
| ミッション | タスク、プロジェクト、優先度、期限、サブタスク、繰り返しを管理 |
| プラン | 日・週・月表示、時間ブロック、習慣、予定衝突の検出 |
| 集中 | 25 / 50 / 90分または任意時間のセッションと生成環境音 |
| ログ | Markdownによる記録とプレビュー |
| Nexus | 自動化、テンプレート、データ診断 |
| 連携 | JSON、CSV、ICS、Markdownのデータ交換 |
| 分析 | 集中時間、完了数、継続状況、ミッション分布 |

## 3. 最初の軌道を作る

1. `Ctrl+N` で最初のミッションを作ります。
2. 「プラン」で今日の時間ブロックへ配置します。
3. 「集中」でミッションを選び、タイマーを開始します。
4. 完了後、ホームまたはログで短く振り返ります。

急いで全機能を設定する必要はありません。「今日やること」と「集中」から始めるのが
最も簡単です。

## 4. NEXUS自動化

初期ルールはすべて停止状態です。ASTERIAが勝手にデータを変更することはありません。

1. 「Nexus」→「自動化」を開きます。
2. 使いたいルールのスイッチをオンにします。
3. 「今すぐ実行」で1件だけ試します。
4. 結果の更新件数を確認します。変更があった場合は通知から元に戻せます。

収録ルールは、期限切れの優先度変更、今日締切の強調、NEXTへの移動、空き時間への
配置、完了ログの記録です。同じ予定やログを重複生成しないよう既存データを確認します。
カスタムルールも表示された条件と処理の組み合わせに限定され、任意スクリプトや外部
コマンドは実行しません。

## 5. テンプレート

「Nexus」→「テンプレート」にはDeep Work Sprint、Weekly Reset、Launch Sequence、
Learning Loopを収録しています。「この軌道を展開」でプロジェクト、ミッション、関連
時間ブロックをまとめて作成し、直後なら一括でUndoできます。

独自テンプレートでは、1行を1ミッションとして保存できます。

## 6. データ診断

「Nexus」→「データ診断」→「今すぐスキャン」で、期限切れ、参照切れ、完全重複、
予定の重なり、長期WAITING、期限切れタイマーを確認できます。

「安全に修復」がある項目だけ自動修復できます。参照解除では本体を残し、重複整理では
古い1件を残し、予定整理では開始順にずらします。修復直後はUndoできます。

## 7. 言語

左下の「設定」→「表示言語」で、OS言語の自動判定または11言語から選択できます。
変更は再起動なしで反映され、次回起動時にも保持されます。アラビア語では本文と操作面が
右から左へ配置されます。翻訳はアプリ内で完結し、タスクやログは外部へ送信されません。

## 8. テーマとモーション

左下の「設定」で変更します。

- 外観: ライト / ダーク / Windowsシステム連動
- カラー: NEBULA / AURORA / SOLAR / 任意アクセント
- モーション: EXPRESSIVE / GENTLE / アニメーションを減らす

任意色を選ぶとMaterial Design 3の色役割が再生成されます。主要な文字と背景は
コントラスト4.5:1以上になるよう自動補正されます。Windowsのモーション軽減設定も
尊重します。

## 9. インポートとエクスポート

「連携」または設定のデータ操作を使います。

- ASTERIA JSON: ワークスペース全体のバックアップと復元
- 汎用CSV: Excelなどとの受け渡し
- Todoist CSV: Todoist形式への変換
- ICS / Google Calendar CSV: Google・Outlookカレンダーとの受け渡し
- Markdown: ログをNotionやノートへ移動
- Trello JSON / CSV: ボード、リスト、カード、チェック項目の取込

これはローカルファイル交換です。OAuthライブ同期や双方向自動同期ではありません。
1ファイルの読込上限は20 MBです。

## 10. 旧版から更新する

1. 念のため旧版からJSONバックアップを作成します。
2. 旧版を終了します。
3. ASTERIA 4.5を起動します。

同じWindowsユーザーであれば、旧データはスキーマ8へ自動移行されます。NEXUSの初期
ルールは安全のため停止状態で追加されます。

## 11. ショートカット

| キー | 動作 |
|---|---|
| `Ctrl+K` | コマンドとワークスペース検索 |
| `Ctrl+N` | ミッションを追加 |
| `Ctrl+Shift+N` | 時間ブロックを追加 |
| `Ctrl+Enter` | 集中タイマーを開始 / 一時停止 |
| `Esc` | ダイアログや検索を閉じる |

NEXUSのタブはフォーカス後に左右矢印、`Home`、`End`でも移動できます。
