# ASTERIA 4.0 — Nexus Intelligence Update

ASTERIA 3.0のSpectrum / Bridge基盤を完成させ、その上にローカル知能層
「NEXUS」を追加したメジャーアップデートです。

## Highlights

- 条件と処理が見えるローカル自動化
- 監査可能な履歴、起動時実行、変更のUndo
- 4つの収録ミッションテンプレートと独自テンプレート
- ミッション、予定、習慣、ログ、自動化、テンプレートの横断検索
- ワークスペース健全性スコアと安全な自動修復
- 任意色対応のMaterial Design 3、ライト / ダーク / システムテーマ
- Google Calendar、Outlook、Todoist、Notion、Trello、Excel向けファイルBridge
- JSON、CSV、ICS、Markdown交換
