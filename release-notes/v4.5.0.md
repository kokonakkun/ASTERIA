# ASTERIA 4.5 — Global Language Update

ASTERIAが11言語で使えるようになりました。言語はOSから自動判定され、設定画面から
再起動なしで切り替えられます。翻訳はすべてアプリ内に収録され、ユーザーのタスクや
ログが外部翻訳サービスへ送信されることはありません。

## Highlights

- 日本語 / English / 简体中文 / 繁體中文 / 한국어
- Español / Français / Deutsch / Português (Brasil)
- हिन्दी / العربية
- アラビア語のRTLレイアウト
- 地域別の日付・数値表記
- Windows通知、トレイ、ファイルダイアログのローカライズ
- 11言語対応の公式プロダクトページ
- 旧スキーマ1〜7からデータを保持したままスキーマ8へ移行

## Important notes

- 専門的な長文UIで個別翻訳がない場合は英語へフォールバックします。
- ユーザーが入力したミッション、予定、ログは自動翻訳しません。
- サービス連携はローカルファイル交換で、OAuthライブ同期ではありません。
- 本EXEはAuthenticode未署名です。SmartScreenが警告する場合があります。
